# \# 🛒 Grocery Management System – Android App

# 

# An Android-based \*\*Grocery Management System\*\* developed as a Final Year Project (FYP). The application is designed to help home users and restaurants manage grocery inventory, track stock, identify low-stock items, compare available ingredients with recipes, and get recipe suggestions based on current inventory.

# 

# \## 📱 Project Overview

# 

# The Grocery Management System provides an easy-to-use mobile solution for managing grocery items and inventory.

# 

# Users can maintain their stock, scan product barcodes, manage recipes, receive low-stock notifications, and find recipes that can be prepared using the ingredients currently available.

# 

# \## ✨ Key Features

# 

# \* 🔐 User Registration \& Login

# \* 🔑 Password Recovery

# \* 📦 Grocery Inventory Management

# \* ➕ Add and Update Grocery Items

# \* 📊 Stock Tracking

# \* 📷 Barcode Scanning

# \* ⚠️ Low Stock Notifications

# \* 🍳 Recipe Management

# \* 🔎 Recipe \& Ingredient Comparison

# \* 🛒 Automatic Shopping List Suggestions

# \* 💡 Recipe Suggestions Based on Available Stock

# \* 🏠 Suitable for Home Users

# \* 🍽️ Suitable for Restaurants

# \## 🗄️ Database

# 

# The application uses \*\*Microsoft SQL Server\*\* for storing application data.

# 

# Main database entities include:

# 

# \* Users

# \* Items

# \* Stock

# \* Recipes

# \* Recipe Ingredients

# \* Sales

# 

# The Android application communicates with the SQL Server database using JDBC.

# \## 🚀 Getting Started

# 

# \### Installation

# 

# 1\. Clone this repository:

# 

# ```bash

# git clone https://github.com/YOUR-USERNAME/Grocery-Management-Android-App.git

# ```

# 

# 2\. Open the project in \*\*Android Studio\*\*.

# 

# 3\. Configure the required database connection.

# 

# 4\. Make sure the SQL Server database is available.

# 

# 5\. Sync Gradle files.

# 

# 6\. Build and run the application on an Android device or emulator.
